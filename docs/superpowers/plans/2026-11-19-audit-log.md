# Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every successful save appends one row to its spreadsheet's `AuditLog` tab in the same
write, and a `/log` page shows the last 20 saves per spreadsheet.

**Architecture:** `writeTabsAtEnd` gains a `form` argument and appends the audit row for the target
spreadsheet to its single `values:batchUpdate`. Config lists spreadsheets with a display name and
audit `TabSpec`. A `logStore` reads the bottom of each audit tab for a new page.

**Tech Stack:** Vue 3, Pinia, UnoCSS, Vitest, Sheets REST API v4.

**Spec:** `docs/superpowers/specs/2026-11-19-audit-log-design.md`

## Global Constraints

- `AuditLog` headers, exact: `savedAt | form | ranges | rows`.
- `savedAt`: WIB (UTC+7) `YYYY-MM-DD HH:mm:ss`, independent of device timezone.
- `ranges` cell is written as `'` + ranges joined by `, ` (keeps the leading quote under
  `USER_ENTERED`). `rows` is the total data rows.
- Form names: `Anomaly`, `Gear`. Spreadsheet display name: `Progression`.
- Log page shows the last 20 entries per spreadsheet, newest first. It never writes.
- Checks: `yarn format && yarn lint && yarn check && yarn build && yarn test`.

## Review Focus

- `AuditLog` tab missing or its header wrong: the save is refused and no data tab is written.
  Test in Task 1.
- A spreadsheet with no audit tab configured: refused before any read. Test in Task 1.
- Empty `AuditLog` (header only): page shows an empty state, not an error. Test in Task 2.
- Fewer than 20 entries: shows all, newest first, without reading the header as an entry. Test in
  Task 2.
- One section's read fails: the error shows in that section only. Test in Task 2.
